Orientação

Como usar o sistema

Este sistema organiza as matrículas dos alunos da academia.

  • Cadastrar: use “Novo aluno”, preencha os campos obrigatórios e salve.
  • Editar: escolha “Editar” na linha do aluno e atualize os dados.
  • Excluir: escolha “Excluir” e confirme a remoção no diálogo.
  • Encontrar: pesquise por nome, CPF ou e-mail e combine com o filtro de situação.
  • Obrigatórios: campos com asterisco precisam ser preenchidos para salvar.
